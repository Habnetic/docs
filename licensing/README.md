# Habnetic | Data sources & licensing

The following files document **what is known**, **what remains unverified**, and **what must be checked before public or third-party distribution** of Rotterdam map data.

- [Rotterdam source and licence evidence](RTM05_DATA_SOURCES_RIGHTS.md)
- [RTM-05 release gates](RTM05_RELEASE_GATES.md)
- [Machine-readable source register](RTM05_SOURCE_REGISTER.json)

These are working records, not legal clearance. Code licence, upstream dataset rights and hosted map-service conditions are separate.

The complete earlier working register, if present in Operations Center, is `docs/licensing/HABNETIC_DATA_RIGHTS_PROVENANCE_AND_PUBLICATION_REGISTER_2026-11-20.md`. This RTM-05 document **updates the evidence** without silently editing that older baseline register (which treated AHN edition as unresolved).
